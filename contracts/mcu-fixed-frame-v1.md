# EcoBin 现有 MCU 固定帧线路契约

> 契约标识：`ecobin-mcu-fixed-frame-v1`
>
> 版本：`1.0.0`
>
> 状态：2026-07-27 已确认，作为 F-11 固定帧适配和 H-03 真机验收的逐字节依据。

本文件冻结现有 MCU 与香橙派之间的固定帧线路事实。香橙派与 OneNet、后端之间仍使用
F-10 规范业务契约；本文件不是第二套云端协议，也不扩充固定帧没有表达的能力。

## 1. 传输约定

- 串口参数：`115200 baud / 8 data bits / no parity / 1 stop bit / no flow control`。
- 线路内容是原始字节，不是十六进制 ASCII 字符串。
- 只支持一个物理投口，对外固定映射为 `portNo=1`；帧内没有投口号。
- 重量字段为 uint24 big-endian，单位克，有效范围 `0..350000`。
- 协议没有 CRC、ACK/NACK、流程编号、消息序号、重发、状态查询和故障枚举。
- MCU 只在取得稳定有效重量后发送结果；线路无法表达称重失败。

## 2. 固定帧

下表中的十六进制值都表示一个原始字节。`PRICE`、`PRE`、`POST` 和 `FULL` 是字段，
不是 ASCII 占位文本。

| 方向 | 功能 | 原始字节格式 | 长度 |
|---|---|---|---:|
| 香橙派 → MCU | 设置单价 | `BB PRICE BB` | 3 |
| 香橙派 → MCU | 启动投递 | `AA 01 AA` | 3 |
| 香橙派 → MCU | 启动清运 | `EE 01 EE` | 3 |
| MCU → 香橙派 | 投递完成 | `DD PRE:u24 POST:u24 FULL DD` | 9 |
| MCU → 香橙派 | 清运完成 | `EF PRE:u24 POST:u24 FULL EF` | 9 |

### 2.1 PRICE

`PRICE` 是一个数值字节，合法值为 `00..09`，分别表示 MCU 屏显单价
`0.0..0.9 元/千克`，不是 ASCII `0..9`。

香橙派把后端万分位单价按下式投影到线路：

```text
PRICE = min(floor(unitPriceTenThousandths / 1000), 9)
```

业务金额仍使用后端原始单价计算；MCU 屏显值不成为结算权威。

### 2.2 PRE、POST 与 FULL

- `PRE`、`POST` 各占 3 字节，均为 uint24 big-endian 克数。
- 投递净重为 `POST - PRE`；清运减少重量为 `PRE - POST`。
- `FULL=00` 表示红外未遮挡，`FULL=01` 表示红外遮挡；其他值非法。
- `FULL` 只是 `DIGITAL_INFRARED + CLEAR/BLOCKED` 原始观测，不是最终业务满溢结论。

## 3. 流程语义

### 3.1 投递

香橙派对一次投递只发送一次 `BB PRICE BB` 和一次 `AA 01 AA`，不因无响应重发。
MCU 保存整场首次重量；用户在屏幕选择继续投递时不发送中间结果，也不覆盖最初的
`PRE`。用户最终结束后只发送一次 DD。

### 3.2 清运

香橙派对一次清运只发送一次 `EE 01 EE`，不因无响应重发。MCU 在清运流程中自动让
继电器通电，并在 3～5 秒后断电。只有以下条件全部满足后才发送一次 EF：

1. MCU 已保存清运前重量；
2. 继电器已经自动断电；
3. 工作人员已经换袋并手动关门；
4. 工作人员已在 MCU 屏幕确认完成；
5. MCU 已取得稳定的清运后重量。

因此，EF 可作为“继电器已断电”和“工作人员已确认关门”的协议事实，但不能证明门磁
检测到关闭，也不能推导继电器健康。

## 4. 接收解析

DD/EF 必须按固定 9 字节解析，不能把数据区内出现的 `DD` 或 `EF` 当成帧尾。接收缓冲
必须处理半帧、粘包和前导噪声，并验证：

- 第 1、9 字节相同且为 `DD` 或 `EF`；
- `PRE`、`POST` 均不超过 350000 克；
- `FULL` 只能为 `00` 或 `01`。

无效候选帧从当前疑似帧头后的下一个字节重新同步。

## 5. 可靠性与恢复边界

- 发送启动命令前丢弃本地接收缓冲中的旧结果。
- 物理启动命令最多发送一次；无线路 ACK 时不能以重发补偿。
- 固定帧模式不发送 `HELLO`、`QUERY_STATE`、配置或恢复帧。
- 香橙派重启后不恢复或重放物理命令，不伪造 DD/EF；未决工作进入明确失败或人工恢复。
- 一条迟到 DD/EF 没有线路作业身份。适配层只能绑定当前唯一活动且类型匹配的本地工作；
  无活动工作、类型不匹配、重复或不可安全归属的结果必须隔离，不能生成业务完成事实。
- MCU 状态、门位、传感器健康和 MCU 重启代际等缺失事实保持 `UNKNOWN`、
  `NOT_SAMPLED` 或明确不支持，不使用 0 或成功占位。

## 6. 显式模式边界

部署必须显式配置且只启用 `fixed-frame` 或 `uart-v1` 一种解析器。禁止自动探测、双解析
和失败回退。需要 CRC、ACK/NACK、幂等命令身份、状态查询、故障枚举或非易失恢复时，
必须明确切换到双方都实现的 `uart-v1`，不能在固定帧上推断或伪造。
