# V-07｜一次真实清运完成换袋

## 目标

让本机构清运员通过真实设备安全完成一次可恢复换袋，使后台得到唯一清运记录、袋追溯、
新重量基准和清运后检测 gate，同时保证首次可能解锁后的不可逆边界、人工关门确认和
设备故障恢复安全。

## 要构建什么

实现清运员扫码设备、选择投口和扫描新袋；建立可恢复清运操作、新袋预留和整机占位；
在香橙派可靠保存上下文和真实解锁前稳定重量后允许电磁阀通电；支持 MCU 屏幕在原操作
内再次解锁、清运员人工关门确认和超时后的原人恢复；通过单一 `CLEAN_COMPLETE` 事件
原子建立清运记录、袋交换、基准、照片槽、检测 gate 和业务确认。

在清运业务启用前新增 `V19` 前向迁移：删除 `rec_organization_clean_config.review_mode` 及其旧 CHECK，删除 `rec_clean_record` 的审核 CHECK、待审索引、审核修订外键和审核/认定列，删除 `rec_clean_revision`；同时为清运记录增加当前有效重量/来源、记录备注、修改版本和更新时间，新增只追加 `rec_clean_record_change`，并建立 `clean.edit` 权限定义。V5/V8/V10 不得回改。迁移必须先断言不存在清运审核修订或依赖其人工认定值的业务数据；若发现历史审核数据则失败并转人工迁移设计，不能静默丢弃。V19 前后总表数都为 83，但历史审核表被修改留痕表替换。

recycling 拥有清运操作、记录、袋、基准和检测事实；device 只经公开端口拥有设备占位、命令和物理事实。事务协调不能转移表所有权。

## 验收标准

- [ ] 清运员必须是当前机构普通用户附加清运能力；管理小程序工作人员身份不能替代清运主体。
- [ ] 创建操作时原子冻结旧袋/基准快照、预留新袋、建立操作和取得整机 CLEAN 占位。
- [ ] 旧袋缺失只产生警告，不阻止清运，也不伪造旧袋身份或事件。
- [ ] 袋只具有不可变身份、当前位置和追加历史，没有“可用/使用中/已清空/报废”等生命周期状态。
- [ ] 开门前重量必须来自本操作的真实稳定采样并已持久 ACK；最近心跳值和失败时的 0 均不可使用。
- [ ] 第一次解锁命令可能执行后不能普通取消或恢复旧袋；系统不声称能够检测清运门实际开关。
- [ ] 多次再次解锁不创建第二操作或记录，不改变首次解锁前重量和新袋预留。
- [ ] 完成必须同时具备清运员人工关门/完成确认、电磁阀断电，以及最终稳定重量或明确
  终态称重故障；物理门位保持 `UNKNOWN`，故障时不建立有效基准并保持投口阻断，
  断电本身不能自动完成。
- [ ] 解锁可能发生后超时或重启保留原操作/投口/袋预留并等待原清运员恢复；未现场确认关门前保持整机占位，确认锁已断电且门扇已人工关闭后可释放整机占位，恢复时重新取得；`SAFE_CLOSE` 不适用于清运门。
- [ ] 只有原清运员能恢复原操作，恢复不重新扫码、不创建新操作。
- [ ] 重复 `CLEAN_COMPLETE` 只形成一条清运记录、一次袋交换、一代基准、四个照片槽、一个检测 gate 和确认任务。
- [ ] 记录、旧袋移除、新袋安装、基准处理、检测 gate 和 device physical result 通过公开端口在同一权威事务收敛，各模块只写自己的表。
- [ ] 新基准无效时保存原值并置 INVALID，绝不沿用旧袋基准或以 0 开放投递。
- [ ] V19 能从完整 V1～V18 严格前向升级，保留清运操作、记录、原始/复算重量、异常、照片、袋、基准和检测事实；清运审核表、列、外键、CHECK 与待审索引全部消失，`rec_clean_record_change` 和 `clean.edit` 建立，V5/V8/V10 checksum 不变。
- [ ] 清运员完成确认直接形成清运记录，不创建审核状态、审核决定、待审队列、钱包、积分、返现或奖励；可靠后端复算重量作为初始有效重量，异常重量保留事实并排除。
- [ ] 有 `clean.edit` 权限的后台人员可以按 `expectedVersion` 直接设置/清空当前有效取走净重量和记录备注；保存与只追加修改留痕同事务、立即影响查询和统计，并发同版本最多一个成功。
- [ ] 修改清运记录不能覆盖设备原始/复算证据，不能暗改清运员、操作、袋关系、基准、容量 gate、投口阻断或设备安全状态。
- [ ] 同一实体袋在本机构反复利用可形成连续位置历史。
- [ ] 真机验收覆盖正常换袋、旧袋缺失、再次解锁、人工关门确认、断网完成、超时恢复和重复事件。

## 排除范围

- 由其他清运员接管恢复操作；
- 清运门首次可能解锁后的普通取消；
- 小程序远程任意开门；
- 袋的生命周期状态或跨机构复用；
- 根据旧基准反推缺失旧袋；
- 绕过 `clean.edit` 与修改留痕直接覆盖清运记录、覆盖设备原始证据、审核/驳回清运记录或因清运发放奖励；
- 设备调拨。
