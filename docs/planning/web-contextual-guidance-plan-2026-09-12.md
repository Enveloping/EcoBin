# Web 页面信息减量与操作提示调整计划

日期：2026-09-12。状态：本地实现、验证及正式部署均完成；北京时间 14:49 激活新版本，公网验证通过。

## 目标与范围

覆盖 Web 路由中的 21 个业务页面及其相关表单、弹窗、详情和导航。默认页面优先展示数据、状态、筛选和操作；帮助只在用户需要的位置出现。沿用 React、Ant Design 和现有业务接口。

本计划仅调整前端呈现与交互，不改变权限判定、订单/钱包计算、设备动作、更新下发、配置生效和异常恢复规则。不提交或部署其他会话正在修改的硬件和契约文件。

## 统一原则

1. 页面副标题默认省略。技术实现、安全实现保证、重复介绍直接删除，不机械搬入悬浮框。
2. 简短的术语解释、填写方法和计算口径放在字段或操作旁的帮助按钮；支持鼠标悬浮、键盘聚焦和点击查看，Escape 关闭。
3. 当前失败、业务被阻止、数据过期必须直接展示，说明影响和下一步；正常状态优先用标签、数值或进度表达。
4. 删除、停用、解绑、永久分配、真实设备更新等后果在确认操作之前直接可见。金额变化在审核/支付前直接可见。
5. 固定流程在相关任务中使用步骤和下一步入口，不在常规列表上常驻教学文字。
6. 常用操作保留短文字；复杂或低频操作按需展开。保留用户可见说明、数据时间、加载反馈、权限控制和提交前校验。

## 实现与验证记录

### 已实现

- 21 个业务页面移除多余标题说明，删去常驻技术介绍和不可用菜单。未将删除的整段文字机械转存为帮助浮层。
- 新增通用 `HelpTip`：鼠标悬浮、键盘聚焦、点击均可查看；Escape 关闭帮助，不连带关闭所在业务弹窗。字段限制及术语解释与对应控件放在一起。
- 厂家操作员在点击“绑定微信”后选择已有用户或扫码；账号设置中的维护公钥登记按需打开。工作人员的机构负责人身份与指定功能授权按选择显示。
- 租户创建后直接衔接建立主体账号，列表保留中断后的下一步入口；启用仍需操作者确认，创建流程不会自动启用租户。
- 袋码页面收为数量、生成、打印规格和批次列表。正常设备/发布状态使用标签，控制板更新计划使用步骤，真实失败、状态未知及业务阻断继续直接展示。
- 投递审核将最终重量、最终金额、钱包余额变化集中为一次确认结果，继续等待服务端核对；核对失败或结果过期不能提交。机构充值在付款前展示手续费及预计到账；新单创建前仅作展示估算，生成订单后使用服务端金额。
- 停用、解绑、删除、永久归属、真实更新、恢复处理等操作保留直接可见的后果。说明中保留“解锁请求已发送但实际是否解锁未知”等事实边界。
