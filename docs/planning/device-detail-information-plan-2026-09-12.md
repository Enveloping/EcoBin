# 设备详情页信息分层调整计划

日期：2026-09-12。状态：已先记录计划、完成实现与验证；用户随后授权提交部署，现已上线为 `20260912073703-8800b3d17c6f`。

## 目标与边界

基于已上线的 Web 页面信息减量调整，进一步整理设备详情抽屉。默认先回答“哪台设备、最近是什么状态、是否需要处理”，其余资料和诊断按需展开。覆盖平台、租户和机构视角。

本批调整前端呈现与交互，不改变业务准入判定、权限、配置命令、验收结果、远程维护会话或设备动作。在线不等于可以投递，历史验收通过不等于当前健康；异常、未知、刷新失败和数据时间不能隐藏。真实操作继续保留原有确认与校验。

## 调整清单

| 区域 | 默认呈现 | 按需查看 |
| --- | --- | --- |
| 设备概要 | 名称、序列号、所属机构、地址、生命周期及必要下一步 | 公开码、型号、租户、坐标、资料版本、资料更新时间、物联网平台名称等设备资料 |
| 设备二维码 | 一个查看入口 | 完整链接、二维码、复制和下载；无法生成的原因在打开后展示 |
| 业务可用性 | 后台返回的准入状态及需要注意的原因 | 管理方式、作业入口、各程序版本、通信协议和记录时间 |
| 待处理问题 | 有问题、加载失败或未知时在概要后展示；保留可执行的处理入口 | 问题编号、原始代码和诊断明细 |
| 最近运行状态 | 联网、当前作业、配置应用情况、联网与运行状态各自的数据时间 | 部件健康完整明细、各类接收/心跳/事件时间及原始状态代码 |
| 部件健康 | 简短汇总，异常和未知项直接可见 | 正常项目的具体状态；不将缺失状态概括为正常 |
| 投口 | 名称、最近重量、满溢和安全/异常情况的简表 | 门控、电磁阀、传感器、观测时间等已有明细 |
| 接入与封存 | 尚未完成或有当前问题时突出阶段、问题和下一步；完成后收起 | 完整步骤、袋码更新次数、验收与封存时间、两份检查记录及任务诊断 |
| 配置 | 当前生效情况，失败时直接显示原因与处理入口 | 配置版本历史、重新下发/修复的适用条件及表单 |
| 远程维护 | 无活动会话时保留入口；活动会话显示状态、到期和关闭；清理未完成继续明确提示 | 公钥准备、连接证书和命令、已结束会话等明细 |
| 顶部操作 | 当前需要的永久分配、恢复；二维码入口 | 禁用、报废、重新核对检查结果等低频操作归入“更多操作”或相关分区 |

默认布局为“设备概要 → 业务可用状态与待处理问题 → 最近运行状态/投口简表”，随后提供设备资料、接入记录、配置和维护入口。长内容使用点击展开，简短解释使用现有帮助按钮，不增加一排新的说明图标。

同一字段减少重复呈现；不同来源、不同阻断原因不因文案相似而合并成同一事实。刷新失败保留旧值时明确标记，页面刷新时间不能替代设备上报时间。展开状态按设备重置，自动刷新不反复打断用户展开操作。

## 完成记录

### 页面呈现

- 抽屉顶部保留名称、序列号、机构、地址和设备状态；二维码通过独立弹窗查看、复制和下载。设备完整资料收起，禁用、报废、重新核对检查结果归入“更多操作”，永久分配及恢复继续直接显示。
- 正常设备默认显示后台返回的业务可用状态、最近联网、作业占用、配置及两类数据时间；软件版本、协议、正常部件明细和额外时间按需展开。各投口默认显示名称、最近重量、满溢和安全情况，异常门控、称重、烟雾以及未知项目仍直接展示。
- 平台问题和读取失败前置；没有问题时省去空问题面板。接入尚未完成时显示当前阶段、问题和下一步，完整步骤与证据收起；只有确认流程完成、验收通过且没有问题或下一步时，接入区域才收为“已完成”并放到运行状态之后。
- 配置历史和恢复操作集中在折叠区，配置读取或应用失败保留直接可见的处理入口。无活动远程维护时保留折叠入口；维护期间直接显示状态、到期时间和关闭，证书、主机密钥、连接命令在详情内查看。会话结束但远程入口尚未清理时，继续显示阻断提示并禁止重新开启。

### 交互与状态保护

- 展开记录或二维码仅触发读取及本地二维码生成，不发送设备命令。已有权限、后台判定、配置参数、命令提交和确认流程保持原有业务边界。
- 切换设备重置展开状态；配置的列表、版本和应用结果均核对当前请求，旧设备迟到响应不能覆盖新设备。远程维护刷新失败明确保留上次结果提示。
- 验证中发现开启和关闭维护表单的“原因”字段使用相同 HTML 标识，已分别命名表单，保证关闭原因的标签与输入框正确关联。
