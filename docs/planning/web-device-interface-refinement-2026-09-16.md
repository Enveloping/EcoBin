## 实施顺序

1. **全局页面密度与分界线**：减少重复页面边距；为完整侧栏增加浅色纵向分界线；为列表表格增加浅色列分界线。已实现，待页面确认。
2. **设备详情去重与渐进展示**：移除重复的业务可用状态、最近运行状态、设备资料、部件与时间明细；日常运营无关数据归入默认收起的“细节数据”；修复展开报修信息导致投口区域高度突增。待第 1 项验收后实施。
3. **设备详情三段结构**：整理为“设备整机数据/状态—投口数据/状态—设备具体配置入口”，一般信息使用紧凑的键值表格。待实施。
4. **设备列表信息调整**：直接显示安装地址；列表中的故障原因改为“状态”，只显示正常或异常，未知按正常展示，具体原因留在详情。待实施。
5. **满溢状态颜色**：重量满溢与红外满溢在未满时显示绿色，已满时显示红色。待实施。
6. **投口重量颜色**：跟随对应投口的综合满溢状态，未满显示绿色，已满显示红色。待实施。

## 第 1 项审查结论

- 主内容当前由 `ProLayout.contentStyle` 增加 22px 内边距，内部 `PageContainer` 又使用组件默认的 40px 横向内边距，形成重复留白。
- 侧栏分界线设置在菜单本身，只覆盖菜单内容高度；空白侧栏区域没有连续分界线。
- 表格主题把表头列分隔色设为透明，数据单元格也没有纵向边界，因此宽表中的相邻列不容易快速区分。

## 第 1 项修改边界

- 由外层布局统一提供 16px 页面边距，并关闭 `PageContainer` 的重复内边距。
- 顶栏高度从 56px 调整为 52px，侧栏宽度从 216px 调整为 208px，菜单行高从 44px 调整为 40px；保留当前信息架构和折叠行为。
- 分界线使用现有冷灰色设计令牌，贯穿整个侧栏；菜单自身不再重复绘制边界。
- 所有使用共享 `data-table-workbench` 配置的主列表，在表头和数据列之间显示浅色纵向分界线；表格单元格略微收紧。
- 本项不修改设备列表字段、详情内容、接口、权限或业务行为。
