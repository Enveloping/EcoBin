# 投递自动审核与投递后自动提现（V53）

状态：已冻结，作为 V53 前向迁移和实现依据。

## 1. 目标与边界

本次在不改变设备、OneNet、香橙派和 MCU 协议的前提下，增加两项机构级能力：

1. 投递订单可以按机构规则自动通过审核；
2. 首次审核产生正向返现后，可以只针对本次返现金额自动创建提现。

历史订单不补做自动审核，历史钱包入账不补做自动提现。已有机构和新机构均保持“全部人工审核、自动提现关闭”的安全默认值，只有发布新配置后才影响之后产生的业务事实。

## 2. 投递自动审核

机构投递审核模式只有以下四种：

| 模式 | 行为 |
| --- | --- |
| `ALL_MANUAL` | 所有投递订单等待人工审核 |
| `NORMAL_AUTO_IMMEDIATE` | 正常订单创建后立即进入可靠自动审核任务 |
| `NORMAL_AUTO_AFTER_24H` | 正常订单从后端接收完成事件起满 24 小时后自动审核 |
| `NORMAL_AUTO_AFTER_48H` | 正常订单从后端接收完成事件起满 48 小时后自动审核 |

订单创建时固化审核模式和自动审核到期时间。延迟以 `backend_received_at`（后端收到完成事件的可信时间）为准，不使用可能漂移的设备时钟。

只有同时满足以下条件的订单才登记自动审核任务：

- 原始计算状态为 `RELIABLE`；
- 原始净重和原始返现金额都不为负数；
- 设备没有上报负重异常；
- 订单不存在任何 `USER` 或 `SYSTEM` 类异常。

照片缺失不属于投递异常，不阻止自动审核。设备完成事件比设备发生时间晚 15 分钟以上时，系统记录 `DELIVERY_COMPLETION_DELAYED` 系统异常，因此该单进入人工审核。

自动审核只能按设备原始结果写入 `ORIGINAL_APPROVED` 的首次审核版本，审核人类型为 `SYSTEM`。若工作人员先完成审核，可靠任务发现订单已不是待审核状态后直接成功结束，不重复入账。技术失败由 `RECYCLING` 可靠任务通道重试；业务不满足条件时结束任务并保留人工审核。

## 3. 投递后自动提现

自动提现只在投递的 `INITIAL_REVIEW`（首次审核）把正金额正式记入钱包时判断。纠错增加的金额不触发，历史余额不参与，本次未触发也不会在条件恢复后追溯补触发。

机构提现配置增加：

- 自动提现开关；
- 自动提现最低金额；
- 自动提现最高金额；
- 自动提现免审阈值；
- 手动提现免审阈值正式生效。

金额规则为：

```text
0.10 元 <= 最低金额 <= 最高金额 <= 单次硬上限 <= 200.00 元
0 <= 免审阈值 <= 对应最高金额
```

自动提现关闭时，三个自动金额字段必须为空。金额小于等于免审阈值时，提现单由系统审核并直接进入 `READY_TO_SUBMIT`；超过阈值时进入 `PENDING_REVIEW`。阈值为 0 表示所有正金额都需要人工审核。

自动提现创建前必须同时满足：

- 入账前钱包可用余额不为负；
- 钱包没有其他活动提现；
- 本次返现金额处于自动提现范围；
- 平台出款闸门为开放状态；
- 机构用户有效、手机号完整，小程序与商户绑定有效；
- 用户的微信免确认收款授权仍为有效状态且身份快照一致；
- 机构可用出款额度足够。

任一业务条件不满足时，本次返现留在钱包，不创建失败提现单，也不影响投递审核提交。机构额度不足只更新一个机构级聚合告警。数据库约束破坏、金额溢出等技术或不变量错误必须使整笔审核事务回滚，交给可靠任务重试或人工处理。

自动提现单、用户钱包冻结、机构额度冻结、系统审核记录和来源决策必须与投递首次审核、钱包入账在同一个数据库事务内提交。微信调用不在该事务中执行；免审单提交后复用现有 `SUBMIT_MERCHANT_TRANSFER` 可靠任务、原商户单号幂等提交和查单收敛机制。

## 4. 幂等与可追溯性

- 每个投递审核版本最多产生一条自动提现决策；
- 每条“已创建”决策最多关联一张提现单；
- 决策保存所用配置版本、返现金额、结果和跳过原因；
- 提现单固化来源类型、来源投递单号、创建时是否需要审核，以及当时实际生效的金额范围；
- 手动提现与自动提现共用活动提现槽位、双侧冻结、微信授权、渠道状态机和终态释放逻辑。

## 5. 微信支付边界

本项目继续使用普通商户 APIv3 的“用户授权免确认模式”。自动提现必须引用已经生效的授权编号；HTTP 返回或单次接口错误不作为资金终态，只有微信原单的明确 `SUCCESS`、`FAIL` 或 `CANCELLED` 才能结束资金收敛。不明确结果继续使用同一 `out_bill_no` 和同一请求参数查询或幂等重试。
