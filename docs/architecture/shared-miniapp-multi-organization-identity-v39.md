## 1. 为什么改变

旧模型把一个小程序 AppID 直接归属于一个机构，因此同一个微信用户只能在该 AppID
对应的机构注册。小程序还把登录页作为启动入口，未登录用户无法先浏览页面。这个模型
不支持多个机构共用同一个小程序，也把微信渠道配置、用户身份和机构业务账号混成了
一个概念。

V39 将它们拆成四层：

1. **小程序渠道**：平台维护的一组 AppID、AppSecret、激活和登录状态；
2. **微信身份**：同一渠道下由 OpenID 唯一识别的微信主体，不属于任何租户；
3. **机构账号**：微信身份在一个租户、一个机构下的业务身份；
4. **当前会话**：一次只选择一个机构账号，并且只携带该账号的租户和机构上下文。

设备公开码只负责定位设备及其永久机构，OpenID 负责识别微信用户。两者组合后创建
对应机构账号，不能把设备公开码当作用户身份或控制凭证。

## 2. 本裁决的效力

本文件覆盖所有较早文档和代码中的下列语义：

- 一个机构必须拥有一个独立 AppID；
- AppID 本身决定登录用户所属机构；
- 直接进入小程序可以创建无设备来源的新账号；
- 小程序必须先进入登录页才能浏览；
- 一个微信用户在同一小程序渠道下只能拥有一个机构账号；
- 机构或租户人员可以维护 AppSecret；
- 设备二维码需要后台异步生成文件并等待 `PENDING / READY` 状态。

旧迁移仍作为 V1～V38 的历史存在，V39 只做前向结构切换；运行代码不得保留旧表读取、
双写或根据 AppID 选择机构的兼容分支。

## 3. 注册、登录与切换

### 3.1 普通进入

小程序首页允许游客立即浏览，并在后台静默执行 `wx.login`：

- 已有机构账号时，按 V49 选择 `last_login_at DESC, id DESC` 排序后的第一个可用账号；
- 冻结账号、已禁用租户/机构或已解除渠道绑定的账号不参与自动选择；
- 没有任何既有账号时保持游客，不创建微信身份、机构账号或钱包；
- 主动退出后保持游客，直到用户主动点击登录或再次扫描设备码；退出前尚未返回的请求
  不得再次触发静默登录。

手工切换成功会在新会话事务中推进该账号的最近登录时间，因此下一次无扫码冷登录继续
选择最近实际使用的可用账号。注册时间仍保持不可变。

### 3.2 设备扫码

设备二维码是普通 HTTPS 地址，业务参数只有完整设备公开码：

```text
https://www.jinshoubao.com/device-entry/?deviceCode=<设备公开码>
```

扫码注册必须同时满足：设备公开码有效、资产机器验收已通过、生命周期为 `NORMAL`、
已经永久分配租户和机构、租户与机构启用、机构绑定当前小程序渠道。设备当时是否在线
不是注册条件，但后续投递仍按实时在线和设备安全事实判断。

满足条件后，系统在一个数据库事务中查找或创建微信身份、机构账号和零余额钱包。
首次注册设备和后端注册时间永久保存；后续扫码不得覆盖。扫描另一个机构的有效设备码
会选择或创建该机构账号，并替换客户端当前会话。无效扫码不得退回最近账号或改写原会话。

### 3.3 多机构账号

- 同一微信身份可以在同一渠道下拥有多个机构账号，包括不同租户下的机构；
- 每个机构账号的手机号、钱包、订单、投递、提现和工作人员能力完全独立；
- 普通用户、清运和管理入口的“我的”页面都可进入统一账号列表并手工切换；管理会话
  只能读取安全身份摘要，选择后签发普通用户或清运会话；
- 扫码选择优先于手工选择和最近登录规则，新的扫码登录必须抢占尚未完成的无扫码登录；
- 会话令牌永远只代表一个机构账号，不产生可以访问多个租户业务数据的平台用户令牌；
- 跨租户查询只允许身份服务按当前微信身份列出安全的账号摘要，业务数据仍由
  `tenant_id` 和机构作用域隔离。

不同 AppID 会得到不同 OpenID。V39 不使用 UnionID、手机号或人工规则合并不同渠道的
微信身份；将来如需合并必须另立决策。

## 4. 手机号与受保护操作

有效扫码成功后立即创建机构账号和钱包，不以手机号授权作为注册事务的一部分。手机号
只绑定当前机构账号；机构 A 已绑定不代表机构 B 已绑定。

- 游客可以浏览公开页面；
- 查看钱包、订单等个人数据只要求登录；
- 开始投递、创建提现、发起商家转账授权等资金或物理操作同时要求登录和当前机构账号
  已绑定手机号；
- 用户取消手机号授权时保留账号和零余额钱包，只停止本次操作；
- 客户端保存原操作和同一个幂等键，授权完成后最多恢复一次。

HTTP 401 不再强制跳转独立登录页。客户端只允许在重新登录仍是同一机构账号和同一入口
时重放原请求；机构账号变化时停止原操作并切换页面，主动退出后禁止自动重登录。是否
展示登录或手机授权面板由用户当前点击的功能决定。

## 5. 数据与资金边界（D-048）

### 5.1 身份表

- `iam_miniapp_channel` 是平台级渠道配置，AppID 全局唯一；一个渠道可绑定多个机构；
- `iam_organization_miniapp_binding` 保存机构与渠道关系，一个机构只允许一个当前绑定；
- `iam_wechat_subject` 按 `(miniapp_channel_id, openid)` 唯一；
- `iam_organization_user` 关联微信身份、渠道、租户和机构，并按
  `(wechat_subject_id, tenant_id, organization_id)` 唯一；
- 小程序用户会话保存渠道、微信身份和一个机构账号快照。

微信身份不是 Web 平台用户，也不拥有租户业务权限。只有选择机构账号后签发的短期会话
才能进入业务接口。

### 5.2 钱包与微信商家转账

钱包继续与机构账号一对一。任何账号列表、自动登录或账号切换都不能聚合或转移余额。

微信免确认收款授权的自然身份调整为：

```text
商户配置 + 小程序渠道 + 微信身份/OpenID + 转账场景
```

四项完全相同时可以在不同机构账号间复用微信渠道授权，但提现单、用户余额和机构额度
仍属于发起提现的当前机构。授权状态查询、创建和同一幂等操作的回放都按上述自然身份
解析；任一项变化都必须重新授权。

## 6. 设备二维码

设备资产不再保存二维码生成任务、对象存储 key、生成时间或等待状态。机构完成永久分配
且绑定渠道后，后端根据全局入口地址和设备公开码即时返回 `deviceEntryUrl`，Web 在浏览器
中渲染和下载二维码。

全局入口基础地址必须是具有有效主机名的 HTTPS 地址，不得携带账号信息、URL 片段或
预先存在的 `deviceCode` 参数。它不属于渠道或机构配置。旧的微信小程序码生成脚本和
已删除登录页面不再保留。

二维码不得包含租户 ID、机构 ID、AppID、AppSecret、OneNet 密钥、设备密钥或部署码。
二维码未配置只影响用户入口展示，不重新引入人工经营开关，也不改变机器验收历史。

## 7. 接口（I-058）

- `POST /api/v1/miniapp/auth/sessions`：AppID 只选择渠道并换取 OpenID；可选
  `registrationSource.deviceCode` 决定机构；无扫码且无既有账号返回
  `IDENTITY.DEVICE_REGISTRATION_REQUIRED`；
- `GET /api/v1/miniapp/me/organization-accounts`：列出当前微信身份的机构账号摘要；
- `POST /api/v1/miniapp/auth/organization-account-selections`：用机构账号 UID 切换并签发
  新的单机构会话；
- 管理会话使用对应的 `/api/v1/miniapp-staff/.../organization-accounts` 和
  `.../organization-account-selections` 身份接口；返回内容仍不包含跨机构业务数据；
- 当前会话响应显式返回 `organizationUserUid`；
- 平台渠道接口维护 AppID、AppSecret、激活与登录状态，并绑定机构；租户和机构
  只能读取不含密钥的渠道摘要；
- 设备资产响应以 `deviceEntryUrl` 取代二维码状态。

错误边界：未扫码注册使用 HTTP 422 `IDENTITY.DEVICE_REGISTRATION_REQUIRED`；无效或不可用
设备入口统一使用 HTTP 422 `IDENTITY.DEVICE_ENTRY_INVALID`；不属于当前微信身份的账号按
404 处理；不可用账号按 403 处理。

## 8. V39 切换与验收

V39 迁移保留现有机构用户、注册时间、首次设备归因、钱包、流水、订单、提现和渠道授权
事实；把旧机构小程序配置迁移为渠道和机构绑定，并按原 AppID/OpenID 生成微信身份。
迁移完成后撤销 V39 前的小程序会话，不迁移正在使用的令牌。

切换前必须备份并保存账号数、钱包数、余额和不可变流水基线；迁移保护查询、表结构、
后端、小程序和 Web 必须成对发布。回退只能恢复整库备份和上一组应用制品，不能只把后端
切回 V38。

验收至少证明：游客可浏览；无扫码的新用户不能注册；已有用户无扫码进入最近登录账号；连续
扫描两个机构形成两个独立账号和钱包；手机号不跨机构；账号切换后令牌仍只有一个租户；
二维码只含设备公开码；同一微信授权可按冻结自然身份复用但余额和提现不跨机构。
