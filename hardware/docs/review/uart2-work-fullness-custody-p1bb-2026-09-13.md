# P1BB：业务内满溢采样组与重量的可靠交接

日期：2026-09-13。状态：本批候选本地实现与验证完成；未部署、未烧录。
上一批见 [P1BA 真实整组采样](uart2-fullness-group-p1ba-2026-09-13.md)。

## 1. 本批接通的路径

实际 McuWorkPreparation（MCU 业务测量执行器）可在启动绑定前显式接入真实超声波来源。
接入后，投递关门后的称重阶段、清运完成请求已保存后的末重阶段，按该阶段的本地测量号
建立一组采样。原重量与真实超声波采样同时推进，各自独立结束；两者都结束后才冻结
一条原业务过程记录。没有新开门/解锁动作，没有后端主动检测任务。

两条既有消息扩展同一个110字节的采样组字段，未新增消息编号：

| 过程消息 | 业务身份 | 正文长度 |
| --- | --- | --- |
| WORK_POSTCLOSE_WEIGHT_READY（关门后重量） | 原投递会话、投口、轮次和配置 | 207字节 |
| CLEAN_FINAL_WEIGHT_READY（清运末重） | 原清运操作、投口、清运动作和配置 | 191字节 |

字段保留采样组编号、完整配置及 MCU 子集的 SHA-256 摘要、开始/完成/最后采集时间、
传感器种类、取值依据、可选代表距离、原请求数量/最少有效数量/阈值、实际完成/有效数量、
组状态和停止原因。组编号不是全局事件序号、启动编号或后端检测编号。

例如重量在本阶段第1020毫秒结束，而超声波要等待原配置的静置时间后才开始采样：
重量的原值、测量方法、样本数、实际耗时和时间戳均不变；超声波完成时间可以晚于重量。
5秒仍是单次称重的最长取值等待，不意味着含原满溢静置时间的整个阶段必须在5秒内完成。
未为配合交接改小满溢静置时间、样本数量或传感器期限。

## 2. 取值、取消与交接边界

- 原始编码器在无组结果时明确写入全零 NOT_SAMPLED（未采样），不泄露复用缓冲区旧内容。
  来源未接入、投口或来源不支持、无法开始时也只能记录未采样，不能改为 CLEAR（未遮挡）。
- 完整组保持 P1BA 约定：有效数足够取中位数；无回波或有效数不足分别保留明确回退依据。
  这些是传感器证据，不是已经更新当前袋子容量或允许接下一单的结论。
- 中断只结束未完成的采集，已完成重量/组结果不被覆写。未完成组保留已完成和有效数量，
  无距离、无传感器判断、无回退；不能把主动中断冒充无回波后判未满。
- 真实组结果和原配置通过 C 编码器进入原业务记录，字节冻结后才退役本地重量及采样组。
  MCU 的过程记录槽继续保留原文，不能用本地退役代替香橙派已保存确认。
- 香橙派沿用实际 EdgeStore SQLite 提交接口，保存完整原业务上下文及全部正文后才产生
  PROCESS_EVENT_SAVED（已持久保存确认）。摘要覆盖新增字段；改变距离但保持原重量，
  即使载荷仍合法，所得确认也不能释放 MCU 的原记录。
- 香橙派重启、确认丢失只重查/重交接原文，不重新称重或发超声波脉冲。保存失败不返回确认，
  数据不会半份落盘。过程确认仅释放这条 MCU 缓存，不释放业务占用、不建单、不触发资金。
- 清运末重及其采样组保存后，仍等待工作人员对当前末重候选确认关门；这条记录不能推定
  清运门物理位置，也不替代人工关门确认。
- 连续投递下一轮使用新的采样组与重量身份；上一轮记录保留，旧距离不补入下一组。
  中间轮次不会因此新增云端业务或按普通满溢阻止当前用户继续。

本批没有给 WEIGHT_ONLY（只按重量判断容量）额外添加采样优化；显式接入来源后仍按上述
阶段采集。是否使用哪轮证据、如何对照原配置和业务确认更新当前袋子，由尚待接通的
香橙派业务消费者负责；不能因为底层数据已保存就宣布当前袋转换/完整准入已经完成。

## 3. 测试发现并修复的实际问题

测试使用真实 C 业务执行器、采样驱动、定时器回调、串口编解码和真实 SQLite；只模拟
GPIO、时钟、回波边沿及秤的物理响应边界，没有以假采样器/假业务状态机替代生产路径。

按 TDD 与 diagnose 的复现步骤，确认了这个失败场景：重量已完成，超声波只采了2次，
此时关门控制状态丢失。原中断路径只调用称重中断；已完成重量保持正常终态是正确行为，
但采样组没有收到业务中断，查询仍返回 NOT_FOUND（过程记录尚未冻结）。同样时序下的
更新停止可以结束采样，排除了记录槽容量和采样时钟没有推进这两项原因。

修复为共享 McuWorkPreparation_InterruptMeasurement，由原动作执行器在验证原业务中断后
调用，同时结束本阶段尚未结束的两种采集。若采样组尚未开始，标记本阶段不再启动；若已
冻结结果，保持原文；若有已完成但尚未取走的真实观察，仍先保存该观察，不能直接丢弃。
投递控制丢失、清运控制丢失/到期、更新停止回归通过。未添加额外机械动作或新的人工门槛。
