## 1. 本批接通的实际路径

香橙派既有 `evaluate_native_work_recovery`（原业务恢复评估）读到完整最终结果时，在
同一个 SQLite 事务快照内继续核对原动作事实。没有增加串口发送、称重、开关门或云端任务。

- 从原 START（开始命令）的真实受理回复，核对本次业务的原动作许可、动作编号、
  命令正文和真实受理回复。只剩“已受理”缓存不算原证据；原命令明确被拒绝却出现输出
  时，报告矛盾，不把它当作普通缺记录。
- 正常投递首轮必须具有同一授权下的 OPEN/CLOSE 两条输出；正常清运首次解锁必须具有
  同一授权下的通电/断电两条输出。复用已有原动作核对逻辑检查首重、事件和时间顺序、
  自动关门或通电脉冲时长，不能只数够两条记录。
- 继续投递逐轮核对本轮 OPEN/CLOSE 与上一轮原 CONTINUE（继续选择）；核对选择事件
  编号和自动关门时长。结果所报轮数之外的输出不能被忽略。上一轮重量凭据缺失时先
  等待重量，之后再读取依赖它的继续选择，不跳过外键约束或用裸重量行替代。
- 再次清运开锁以原按钮步骤为依据查找它自己的动作，不仅遍历当前尚存的命令行。
  即使某次命令和两条输出一同缺失，也不能拿首次解锁记录凑成完整结果。
  普通重新开锁仍沿用同一清运许可和原 START；恢复代际的开锁不混入普通开锁证明。
- 清运中间每个步骤必须有原“请求完成”或“请求开锁”记录，且事件和时间顺序一致。
  缺某一步时返回该步骤的两种可查询范围，表示二选一的原始类型尚未确定，不是要求
  人工重新按两种按钮。正常最终步骤仍由原请求完成、末重和人工关门确认共同核对。
- 投递的每轮关门输出必须早于该轮测量开始；清运断电记录必须早于最终测量开始。
  使用原 MCU 时间与事件序号，不用香橙派收包时间重新排序。

例如：清运员先请求完成取得700克候选，又重新开锁，再请求完成取得900克并确认。
最终结果仍用900克对应的候选；这次重新开锁的按钮、命令和输出也必须有自己的原记录。
缺任何必要记录只保留现有结果等待补齐，不重新开锁、不清除原业务占用。

## 2. 缺失、冲突及返回证据

外层继续返回 `COMPLETE_RESULT_AVAILABLE`（已有完整结果），即使 MCU 已重启，也不能
将“完整结果尚缺配套证据”改成“最终结果丢失”，或建立基于结果不存在的恢复意图。

内层 `evidence.state` 区分等待原过程、原配置、原命令或原输出证据；`missing` 保存
精确的业务范围、命令身份或逻辑动作键。最终结果没给出的事件编号不会被猜造。
`execution` 返回已核对的受理原文、命令和许可/动作快照、原输出及首轮动作证明。
许可/动作转换为普通数据字段，保留正文 bytes 的既有表示，能够由隔离发布包进程复读。

新增 `EdgeStore.list_native_work_actuator_events` 同时按索引及正文中的业务编号查找，
再复用原存储校验器；篡改索引不能把正文仍属于本业务的记录藏起来。此方法只读、不改表结构。

`MATCHED` 仅表示本入口已覆盖的原证据一致，不等于称重正确、门物理关闭、配置全部
实际应用、永久账本已确认、正常业务上报完成、当前袋切换或资金授权。
本入口不写动作确认、不消费分类待办、不清占用、不建订单/余额/返现/提现。
清运断电仍不能替代工作人员关门确认。

失败/取消结果不被强套正常 OPEN/CLOSE 或完整脉冲条件；保留已发生的部分输出。
完整中断原因、恢复动作与失败结果的对应策略仍需后续实现，不能据此称全部异常已核对。

## 3. 测试与本轮发现

按 TDD（先验证目标行为失败，再实现并回归）推进。新增 `test_native_result_execution.py`
42项，使用实际 C 业务/计时器/协议、实际 Pi 许可与 SQLite；仅模拟物理输入、时钟、
串口和按钮边界。缺失/矛盾在临时 SQLite 注入，读取和补交均调用正式接口。

- 新反例证明原实现会漏掉“再次开锁命令与输出全丢”的情况，改用原按钮步骤查找。
- 原有连续第二轮测试没有交接该轮输出，现补实际 MCU 查询/保存/确认链；交接前正确
  等待输出，交接后通过，不改成伪造两条测试记录。
- 包隔离测试暴露新返回值中的许可/动作对象无法沿既有 JSON 比较边界序列化；将结果
  中的对象投影为普通字段后，业务包和运行时包均能重开真实数据库并得到相同证据。
- 测试准备中纠正了调用参数，以及依赖选择与重量的删除顺序；保持 SQLite 外键开启。
  不把准备错误算作产品缺陷，实际行为反例已分别观察到失败后再修复。
- 测试覆盖缺整组或单条输出、错误方向/时长/测量先后、缺受理原文、拒绝与输出矛盾、
  复制索引损坏、中间步骤缺失、原按钮顺序错误及超出结果轮数的输出。
