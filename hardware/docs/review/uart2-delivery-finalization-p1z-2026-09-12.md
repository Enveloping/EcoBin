# P1Z：MCU 选择窗口与首次投递最终结果

日期：2026-09-12。继续已授权计划。本批只修改候选实际 C 执行器及本地测试，使用模拟时间、
GPIO/传感器边界和合成 SQLite 数据。未 SSH、连接真实串口、改 HMI、部署或烧录。
整体 P0～P7 目标仍在进行；不能把首次投递的局部完成路径当作 P3 全部完成。

## 本轮实际行为

首次授权、自动关门和关门后新测量承接 P1W/P1X；本批把 P1Y 的选择交接接到实际执行器：

1. 同轮关门后重量未取得精确保存确认时，继续保留原文，不启动选择窗口。
   MCU 前台首次观察到对应原命令/业务/轮次/配置/测量身份的保存确认后，启动本次已冻结
   `continueDeliveryWaitMs` 时长的窗口。重复轮询、查询或迟到确认不重置倒计时。
2. 新前台入口 `McuDeliveryExecution_Select` 接受 CONTINUE 或 END，调用者必须提供
   **屏幕显示的那轮测量编号**。旧测量编号、窗口尚未开始、已过截止点、已有选择、已完成
   或回退/超过真实 MCU 时钟的调用均拒绝。该入口不接收外部伪造的 WINDOW_EXPIRED。
   本批只接收按钮意图，物理 HMI 串口解析/页面绘制仍未接入；后续不能把迟到按钮改贴当前轮次身份。
3. MCU 在窗口截止时生成 WINDOW_EXPIRED。前台即使延迟运行，仍保留原截止时刻，不续期。
   第一个有效选择确定后不被另一按钮或超时改写，使用共享全局事件编号，关联原 START 和
   本轮关门后重量，经既有单过程保留槽查询、Pi 同事务保存及精确确认。
4. END 或 WINDOW_EXPIRED 的原文精确保存后，MCU 核对仍为逻辑 CLOSE、动作未失效且
   没有更新停止，再从已保留的首末测量直接组装唯一 `WORK_RESULT`，不重新称重。
   结束时刻是原选择/窗口截止时刻，不是迟到确认时刻。PB5 只暂停关门输出，本身不阻止
   这次逻辑关门结果，也不被写成实测门位；`physicalCloseConfirmed` 仍不用于投递。
5. 本轮关门后测量确实不可用时，不产生用户选择。其失败测量原文保存后，组装带原测量
   编号、样本数、耗时和明确故障的 FAILED 结果；缺值不是测得零，也不复用首次重量。
   最终 Pi/后端如何把它归为系统异常订单仍待业务分类接线，不在本批制造订单或余额。
6. 第一轮开门前与关门后重量减少达到原 START 冻结阈值时锁存负重量异常；最终结果携带
   布尔值，不上报中间减少值。本批执行器仍只有首轮，后续继续轮次必须改用对应本轮前重，
   累计锁存且不能在同一场继续投递中清除。
7. 最终结果保留到香橙派精确确认；Pi 原文和待分类任务在同一提交中保存后才确认。
   Pi 单独重启、确认发送前丢失或 MCU 收到确认后回复丢失，都只查询同一结果，不重开门、
   不重测、不重复创建待分类任务。Pi 原业务占用仍保持，云端/资金流程未启用。
8. 下一笔真正的新 START 和首次授权会重置本执行器的选择窗口、首末重量和异常标志，
   不把上一笔已释放结果套到新业务。RS485 请求的 250 毫秒最小间隔仍跨测量窗口保留。

CONTINUE 现已由真实 C 接收并保留，但**尚未启动下一轮机械动作**，不会改成 END 或伪造完成。
后续须把原业务内新动作、实际永久动作账本和本地前置检查接通；不能重放第一次开门授权，
也不能把选择已保存直接当成全部动作许可。

## 本地验证

采用 `tdd` 技能逐段测试后实现，实际观察到超时选择 NOT_FOUND、结果仍 RUNNING、缺少按钮
入口、阈值未锁存和未来时刻可伪造选择等失败，再分别实现与回归；未用测试状态机代替生产 C。

- 新增专项 **19 passed**：未保存重量不开始窗口、超时唯一性、结束按钮、旧身份/重复按钮、
  期限等值和迟到边界、跨 32 位时钟边界、未来/回退时间、配置 1000 毫秒窗口、5 秒中位数、
  无值/不足五点失败、负重量阈值边界、PB5/更新停止、CONTINUE 不假完成和连续两笔隔离。
- 三项完整实际 C + Pi + SQLite 联合场景覆盖无丢包、最终确认发送前丢失和确认回复丢失。
  前置重量、选择和最终结果都沿实际查询链交接。每次最终确认发送前，第二个 SQLite 连接
  读回已提交原文和唯一待分类任务；重启后测量序号保持 2，Pi 占用未提前释放。
- 专项与既有准备、首次执行、关门称重、选择交接、最终交接及容量检查组合 **92 passed**，
  23.82 秒。组合与专项重叠，不相加。
- 两个新增场景的测试准备曾不符合真实接口：自定义配置漏提供重算摘要，以及下一笔立即
  在距上一请求不足 250 毫秒时发起采集。已按真实摘要/请求间隔修正准备，没有放宽运行校验。
- 104 个生成物一致性检查通过。Registry **rc.13**、SQLite **schema24**、线级布局均不变。
- Clang 对本轮执行器静态分析无诊断。ARMCC5 核心链接探针 Code38416、RO1868、RW56、
  ZI5616，即 ROM **40340** / 静态 RAM **5672** 字节；相比 P1Y 增加 1316 / 32 字节。
  探针明确保留新按钮入口，只链接 `DO_NOT_FLASH`，不证明正常 main、全部驱动或完整中断栈。
- 最终扩大回归：1152 passed / 34 skipped / 1624 subtests passed，零失败，254.94秒。包括当前契约、native MCU/Pi、旧串口/业务存储及恢复相关组合；不是全仓或实机验收。34个环境相关跳过沿用原范围，不计为通过。历史SQLite强杀恢复偶发I/O问题本次未出现，仍不宣称已修复。

历史 Windows SQLite 强杀恢复偶发 I/O 问题仍保留，不因本批改动而宣称修复。
