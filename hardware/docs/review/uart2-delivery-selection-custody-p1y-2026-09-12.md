## 实现与业务边界

关门后称重原文已保存，再记录该轮的继续、结束或选择窗口到期。选择明确关联原 START
命令、原投递、投口、轮次、配置版本和该轮关门后测量编号，不能关联到另一次称重。
例如同一轮已保存 END，后来收到同轮 CONTINUE，不覆盖原记录、不重新确认；保留冲突
供排查，阻止这条交接继续推进。重连或香橙派单独重启不会消除该冲突。

- 唯一 Registry 推进为 `2.0.0-rc.13 / DELIVERY_SELECTION_CUSTODY_NOT_RUNNABLE`。
  `DELIVERY_SELECTION` 增加原 `mcuCommandUid` 和 `configVersion`，正文 80 字节、总帧 94 字节。
  仍共 63 条消息，不新增第二套确认报文。
- 新增 `processEventMessages` 集合：六类既有称重加选择；原 `processMeasurementMessages`
  仍只有六类称重。选择进入完整字段、UUID、边界、摘要与帧标记校验，但不是一份重量。
- C 单过程保留槽只允许在同作用域关门后重量精确保存后保留选择。核对原命令、业务、轮次、
  配置、测量编号、事件顺序和 MCU 运行时间；来源必须为可用均值或中位数。
  未确认重量不能被选择覆盖，旧重量确认不能释放选择，普通 ACK 不替代精确保存。
- Pi 复用按原步骤查询与 `PROCESS_EVENT_SAVED` 精确确认。选择、原始正文和其已保存重量
  关系在同一事务校验并提交；提交失败不发确认。保存确认丢失后查询同一条原记录，不重测或重开门。
- SQLite 保留数据迁移到 **schema24**，增加独立 `native_delivery_selection` 表，外键指向
  已精确保存的关门后重量；同启动/业务/轮次只能有一个选择。原称重、动作、最终结果表不改写。
- 称重、选择、动作不得复用同一个 MCU 全局事件编号。双向到达顺序均检查；矛盾正文、
  矛盾查询与原文均留档，已发现冲突不会因下一次收到“正确原文”或 Pi 重启而自动清除。
  复用历史命名的 `native_actuator_event_conflict` 作为跨类型交接冲突档案，不代表选择是动作。
- 运行时清单声明 schema24，并补入 `mcu_process_handoff.py`，避免候选安装后缺少实际依赖。
  正常 main 未启用新协议，旧部署认可/兼容接收面没有放宽，不能据此直接更新旧卡。

本批只完成**选择事实的保留、查询、保存和确认**。屏幕按钮或倒计时如何产生选择，
CONTINUE 如何触发下一轮，END/到期如何组装整场结果，仍待接入业务执行器。
联合测试中的选择意图明确由测试边界提供，不能说实际 HMI/超时已接通。
保存成功不释放业务占用、不生成云端任务、不建订单、不增加余额或触发提现。

## 验证与发现

依照 `tdd` 技能逐步验证原作用域、保留槽、真实 SQLite 与实际 C/Pi 查询链：
先观察失败，再做实现，没有用另一套测试状态机替代生产 C。

- 最初 50 项新专项全部通过：三类选择、非法字段、未保存/不可用/错误轮次来源、重复/冲突、
  不同记录类型复用事件编号、提交失败、提交前后进程退出、schema23 升级、丢确认与 Pi 重启。
- 实际 C/Pi 联合测试发现控制入口遗漏选择帧的 `ACK_REQUIRED` 标记，真实 Pi 因此拒收；
  已补入实际发送分支，再验证原文提交先于每次精确确认。独立 SQLite 连接能在发送前读到原文。
- 首轮扩大回归为 **1130 passed / 34 skipped / 1624 subtests passed / 2 failed**，262.52 秒。
  一项是错误样本生成器把标记写死为 0，正文负例先被帧标记拒绝；另一项是模拟 schema18 的
  测试漏删 schema24 新表。二者均保留原失败结论，没有删断言、放宽校验或新增跳过。
- 按 `diagnose` 技能最小复现样本问题，再新增公开解析器回归。样本现从 Registry 取确认标记，
  证明坏正文被正文校验拒绝、后续完整帧仍可接收。升级测试补删新表，并在注入崩溃前验证
  模拟旧库确实没有任何原生协议表。修复后的新专项及旧库原子升级组合 **52 passed**。
- 独立完整契约验证 **25 passed / 0 notes**：104 生成物、43 帧、1242 流轨迹、9 摘要，
  参考 Python、生成 Python、Java 21、独立头文件 C 和共享校验 C 一致；49 条完整消息守卫。
- Clang 对过程槽和控制入口静态分析无诊断。ARMCC5 核心链接探针 Code37104、RO1864、
  RW56、ZI5584，即 ROM **39024** / 静态 RAM **5640** 字节，比 P1X 多 408 字节 ROM、RAM 不变。
  `DO_NOT_FLASH` 只链接探针，不是正常 main、全部驱动/中断栈或可烧录完整固件证明。
- 最终扩大回归在上述修复后重新执行，**1133 passed / 34 skipped / 1624 subtests passed，零失败**，
  251.64 秒。范围包含全部 `contracts/tests`、选择/投递/称重/过程与动作交接、配置/会话/事实、
  最终结果槽、SQLite/进程退出、安装/更新、旧固定帧与永久账本相关套件；未排除首轮失败用例。
  SQLite 强杀恢复本次通过，但历史偶发错误根因仍未确定。
- 跟踪文件 `git diff --check` 及本轮新增源码/测试/记录的行尾空白检查通过。
