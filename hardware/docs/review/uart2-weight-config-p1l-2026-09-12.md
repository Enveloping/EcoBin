# 原生 UART 2 称重配置与摘要 P1L

日期：2026-09-12，承接 [P1K 完整配置集合](uart2-config-collection-p1k-2026-09-12.md)。本地候选，未部署或操作设备。

## 参数与兼容边界

Registry 为 `2.0.0-rc.8` / `NATIVE_WEIGHT_CONFIG_NOT_RUNNABLE`。
单片机配置摘要改为 `MCU-CONFIG:v2`、layoutVersion=2，明确与旧版摘要不同，不猜测或补齐旧参数。

原生首版将已确认规则固定为：全机和投口最多 5000ms、最近 5 点最大最小差不超过 100g 取均值、
目标轮询间隔 250ms；纯波动超时取本阶段合法点中位数。工程候选同时显式携带：响应期限 200ms、
稳定窗口最大跨度 1500ms、最后点最大年龄 750ms、中位数最少 5 点。工程值还须经真机验证；
当前用 Registry const 固定同一首版配置档，不让重复参数冲突或未经验证的自由组合悄悄生效。
测量量程、校准版本仍为显式配置，不自动校准，也不把缺失读数当 0。

所有上述参数进入完整摘要。设备分段正文 183 字节/总帧 197 字节，投口分段正文 207 字节/
总帧 221 字节，均在 256 字节以内；六投口摘要原文 440 字节，集合结构仍不超过 512 字节。

## 实际实现

- Python3.11、C、Java 的生成校验同时拒绝旧 6 秒/10 点配置及与本档不符的参数，即使单条命令摘要正确。
- C 集合增加类型化称重配置读取，直接从已完整核对的摘要原文取得全部参数及配置/校准版本，
  没有另填默认值。实际 C 称重核心使用该配置完成 0 克稳定均值和 5 秒波动中位数测试。
- 新增 Pi `NativeMcuConfiguration`，只接收显式单片机字段集合，验证整套摘要并冻结为不可变对象；
  为每个分段编码时必须提供真实应用/命令/启动/序号。输入字典后续变化不改变已冻结的配置。
  不分配身份、不持久化、不发串口、不授权配置操作、不自动重发。
- Pi 编码分段直接交给实际 C 集合核对，完整摘要及投口参数一致。并非只比较 Python 两份字典。
