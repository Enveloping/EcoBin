# UART 协议临时兼容约束

> **已被正式入口取代（2026-07-25）**：F-11 正式入口和当前真机 HIL 使用 UART 1.0。
> 本文只记录仍留在旧文件/测试中的 AA/BB/CC/DD 与 D1 历史边界，不得作为新功能或
> 生产失败回退协议。当前 HIL 证据见
> [`uart-hil-2026-07-25.md`](uart-hil-2026-07-25.md)。
>
> 记录日期：2026-07-17。本文用于防止联调阶段的临时规则被误当成最终设计。

## 当前临时规则

- 只支持一个物理投口，对外固定为 `doorIndex=1`；UART 帧不含投口号。
- `unitPrice` 虽为浮点数，但 MCU 只有一位价格数据。香橙派使用
  `floor(unitPrice × 10)`，因此 `0.45` 会降精度为 `0.4` 元/kg。
- 可配置单价仅限 `[0.0, 1.0)`；达到 1 元/kg 后现协议无法表达。
- 协议没有 CRC、独立 ACK、命令序号和自动重试。AA 状态帧只用于确认物理门状态。
- 新 AA/BB/CC/DD 协议本次只接入投递流程。清运仍保留旧 D1 文本代码路径，
  尚未适配新 MCU 固件，不能据此认定清运已可联调。

## 后续升级触发条件

出现多投口、单价达到 1 元/kg、需要保存两位小数、现场串口干扰、重复命令或清运 v3
任一需求时，应升级协议版本，而不是继续扩展当前无版本号帧。升级至少需要统一：

- 帧版本、消息类型、投口号、载荷长度和 CRC；
- 命令序号、ACK/NACK、超时与幂等重试；
- 可表达真实金额精度的定点单价格式；
- 投递和清运各自完整的状态机及异常恢复语义。
