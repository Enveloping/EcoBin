# 香橙派镜像制品目录

本目录统一管理 EcoBin 香橙派镜像的来源、候选构建、真机 HIL（硬件在环）
验收和写卡证据。Git 管理的是可复现配方、清单、摘要、签名和脱敏证据，
不是含凭据的镜像二进制本体。

## 目录边界

- `candidates/`：无密钥候选镜像的构建清单、锁文件、SHA-256 和介质资格证据；
- `evidence/`：写卡结果、HIL 资格证据、分离签名和公开验签密钥；
- `local/`：本机实际镜像、上游压缩包、含 K1 的工厂母镜像、环境配置和历史源码
  bundle。该目录内容由 `.gitignore` 强制排除，只保留 `.gitkeep`；
- `artifact-catalog.json`：本地制品与 Git 证据的统一索引。对低熵凭据文件只记录存在性，
  不记录内容或摘要。

## 安全规则

1. `.img`、`.env`、私钥、设备密钥和服务器凭据不得提交 Git。
2. 含 K1 或设置热点密钥的镜像必须按机密制品保管；即使设备首次注册后删除逻辑文件，
   原始镜像仍包含相同字节。
3. 公共验签密钥可以跟随证据提交，但签名私钥必须保留在仓库外受控位置。
4. `local/` 中的文件不会随 Git 克隆恢复；恢复时按 `artifact-catalog.json` 和候选清单
   重新构建或从受控制品备份取回。
5. 新证据提交前必须运行仓库现有镜像校验测试，并检查 Git 暂存区没有敏感文件。

本地制品有增删后，在仓库根目录执行：

```powershell
pwsh -File tools/orangepi-image/update-local-artifact-catalog.ps1
```

该命令会重新计算镜像、上游包、源码 bundle 和证据的 SHA-256，但不会读取或记录
`.env` 的值及摘要。
