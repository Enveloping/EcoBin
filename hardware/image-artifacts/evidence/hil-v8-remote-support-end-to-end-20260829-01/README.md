## 本轮发现并关闭的问题

1. 封版防火墙原先没有 SSH 出站权限；H616/Air780E 还会把部分新 SSH SYN 判为
   conntrack `invalid`。提交 `35bdde30` 在 `invalid-output` 前增加低权限代理账号的窄
   出站例外。
2. 首轮修复后控制面可以达到 `OPEN`，但跳板端口读不到设备 SSH 标识，设备在
   ServerAlive 超时后重连。双向计数试验证明返回数据也会被判为 `invalid`。提交
   `a1d4136f` 把出站继续收紧到代理 UID、凭据解析出的跳板 IPv4 和 SSH 端口，并在
   `invalid-input` 前仅允许同一 RNDIS 接口、跳板源 IPv4 和 SSH 源端口的返回数据。
   该返回例外不匹配设备目标端口 22，不开放新的公网入站 SSH。
3. 热部署时，常驻的 `ecobin-first-boot` 每 3 秒执行封存清理并用内存中的旧模块重放
   生产规则，会覆盖仅在磁盘替换的新实现。最终部署同时重启首次启动协调器和蜂窝协调器，
   跨多个协调周期复核规则仍保持。受控重启导致 MQTT 短暂恢复一次，之后没有新断线。
