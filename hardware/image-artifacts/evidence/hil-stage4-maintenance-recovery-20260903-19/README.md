## 第四阶段安全边界

v19 固化了第四阶段激活和恢复路径的安全修正，以及 systemd 维护单元围栏的严格验证。离线
核验确认：

- 镜像中的 8 个 systemd 单元及各自安全围栏均符合预期；空条件重置、畸形条件、重复或冲突
  条件以及不可接受的控制字符不会被维护安装器当作有效配置；
- 更新控制命令行程序只归设备更新器组件所有，业务程序和通信代理没有复制该特权入口；
- MCU 固件恢复路径和首次启动协调器内容均与本次源码一致；
- 第四阶段永久作业闸门保持默认关闭，通信代理不接管 OneNet，设备更新器不执行远程业务程序
  或 MCU 更新，特权维护路径不接受第四阶段变更动作；
- 构建后的镜像不携带运行中的维护状态，不能因构建或注入测试输入而把设备误标为正在维护。

这些结果只证明镜像包含默认关闭的安全基础，不代表通信代理、更新器、后端发布控制面和真机
