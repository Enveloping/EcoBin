# v9 可信校时与自动接入恢复证据（2026-08-30）

## 结论

指定单卡写入 v9 后，局域网页 P7 验收已经通过，Air780E 的 USB/RNDIS、地址、默认路由、
DNS 以及到外部服务的 TCP/TLS 路径也正常，但设备长时间停留在出厂热点阶段。现场复现证明，
阻塞点是首次启动协调器在 `chronyc burst`（异步时间测量）尚未完成时立即恢复紧急全拒绝
防火墙，导致 chronyd 只能取得触发大幅校时的首个样本，无法取得令操作系统确认
`NTPSynchronized=yes` 的后续样本。设备因此不能继续 HTTPS 自注册和正式运行。

修复后，受限 RNDIS 防火墙在校时 `PENDING`（仍在收敛）期间继续只开放既有最小出口；设备
注册、UART 交接和正式运行仍等待操作系统的可信时间事实，不会提前放行。真机随后自动完成
可信校时、HTTPS 自注册、K1 清理、正式凭据落盘、运行目标启动和 OneNet/MQTT 上线。后端
资产已经创建并显示 OneNet `ONLINE`；当前机器验收尚未开始，是因为这个单投口设备还没有
登记厂家初始袋，出厂热点继续保留符合 P8 封存状态机预期。

## 原故障与根因

- 初始墙上时间仍在 2026-04-27，而实际日期为 2026-08-30；HTTPS 因服务端证书在设备视角
  “尚未生效”而失败。
- 四个 NTP 服务器的受控 SNTP 探针均能收到合法响应，排除了 Air780E、DNS、路由和 NTP
  服务本身故障。
- `chronyc refresh` 在每个协调周期重新解析并替换来源集合，会丢掉已有样本；`burst` 返回
  只表示 chronyd 接受异步任务，不表示时间已经可信。
- 第一个有效样本可先触发大幅时间跳变；只有在跳变后继续取得样本，systemd 才会发布
  `NTPSynchronized=yes`。旧协调器在此期间恢复紧急防火墙，阻断了这些后续 NTP 报文。

## 修复内容

1. 校时结果由布尔值改为 `SYNCED / PENDING / FAILED` 三态。
2. 解析 `chronyc activity`；已有解析完成的来源时不再执行 `refresh`，已有 burst 在运行时
   不重复叠加 burst。
3. 每次调用只执行有界等待。仍未收敛时返回 `PENDING`，保留严格的 FACTORY 出口规则供
   chronyd 在协调周期之间完成；命令错误、无时间源等硬失败仍立即恢复紧急全拒绝。
4. `timedatectl` 命令失败或输出无法解析按硬失败处理；只有其明确返回 `yes` 才允许注册和
   正式运行继续。

  `7b055e3f4cf826570cea333c0542344f26e9d36fc9c2d5d4cd5fa296bdf5e6ee`

## 回归与真机结果

- 测试先以“已解析来源不得刷新”和“异步校时待定时不得关闭受限 NTP 窗口”复现，修复前
  精确失败 2 项，其余 12 项通过。
- 聚焦回归：`18 passed`。
- Windows 上按目标 Python 3.11 运行完整设备侧回归：
  `1000 passed, 46 skipped, 5 subtests passed`。
- 真机 `timedatectl NTPSynchronized=yes`；chrony 选中 stratum 2 来源，复核时系统偏差约
  0.45 毫秒，闰秒状态正常。
- 首次启动、蜂窝、注册、运行门禁、硬件网关和远程维护代理均为 active；设备到 OneNet
  `183.230.102.116:1883` 的 MQTT 连接保持 established，并收到属性/事件上报响应。
- K1 与注册中间态已删除；正式设备凭据和 P7 安全交接事实存在；设备仍未封存。
- 后端注册记录为 `READY`，OneNet 设备已创建；资产机器验收为第 0 代 `PENDING`，OneNet
  传输投影于 `2026-08-30T05:56:46Z` 收敛为 `ONLINE`。
- 厂家初始袋、验收证据和封存授权当前均为 0 条。因此下一业务动作是厂家操作员为唯一投口
  扫描并登记一张平台 EB1 初始袋码，之后后端才自动发起机器验收。

## 清理与证据边界

真机热更新前的临时回滚副本位于 `/run/ecobin/codex-time-sync-hotfix-20260830`。稳定复核完成
后已核对其规范化绝对路径并删除；这是易失性临时副本，删除后不能从该目录恢复，仓库旧版本
仍可用于代码级回退。

本证据证明 v9 在当前单卡和当前测试环境中能够从 P7 继续自动校时、自注册并接入 OneNet。
它不把尚未登记的厂家初始袋、尚未发生的后端机器验收或 P8 单向封存写成已完成，也不包含
K1、设备密钥、热点密码、数据库口令或服务器凭据。结构化脱敏事实见
[verification.json](verification.json)。
