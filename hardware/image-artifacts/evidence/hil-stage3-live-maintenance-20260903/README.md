# 第三阶段永久设备管理层原位安装与在线验收证据

本目录记录 2026-09-03 通过 COM3 调试串口，在当前 v13 单卡开发/硬件在环设备上执行的
第三阶段永久设备管理层受控维护安装和在线低权限验收。最终使用的安装载荷来自干净提交
`4120579c5a7d7243e8d3d6db0b537065b9ead529`，安装结果为 `PASS`。

这里的“原位安装”是指通信代理、设备更新器、低权限用户、systemd 单元、Unix Socket、
状态目录和两个固定特权助手已经写入真实系统目录，并由生产 systemd 单元运行；它不是此前
位于 `/home/orangepi` 的普通用户影子测试。当前旧业务程序仍负责真实 OneNet、UART、摄像头
和业务流程，第四阶段及远程更新能力继续关闭。

## 首次安装失败、自动回滚与保留状态处理

r2 载荷的安装操作
`op-20260902192401-stage3-maintenance-v13-2-62b61ca3` 在安装后审计中发现更新器两个私有
子目录的用户组被 systemd 递归改写，不符合更新器私有目录的权限约束。安装器没有忽略错误，
而是自动执行回滚；记录最终为 `ROLLED_BACK`，`automatic=true`，且回滚错误列表为空。

回滚刻意保留了已经创建的通信代理和更新器 SQLite 数据库，避免把未知持久状态当作临时文件
删除。重试前，维护工具逐项核对这两份数据库是普通文件、没有符号链接或额外链接、所有者和
权限正确、SQLite `quick_check` 返回 `ok`、格式版本为 0，并且设备没有活动维护安装标记。
核对通过后，它们被原子移动到：

```text
/var/lib/ecobin/device-management-maintenance/backups/
op-20260902192401-stage3-maintenance-v13-2-62b61ca3/
retained-state-before-r3-retry
```

归档状态为 `ARCHIVED_FOR_R3_RETRY`。归档通信数据库 SHA-256 为
`f3f890611a930aefa0980abc0de43d762a2ca00d2d4e80da74db6e352421b73a`，更新器数据库
SHA-256 为
`aa51e49d71812b84623ee42ed9472a870a0ab4f46e2b15c957aa878a2f0af17b`。没有手工删除或
修改这次失败产生的数据库来伪造干净重试条件。

r3 修正 systemd 接管顶层状态目录时不应改变两个私有子目录用户组的问题。重试前只读预检
确认受保护的 v13 首次启动闸门仍与镜像一致，六个旧硬件发布目录只需增加目录穿越权限，
保留的三个服务身份可以安全复用；演练安装和正式安装随后均通过。

## 最终状态与清理

正式 r3 安装记录保持 `INSTALLED`，永久组件及 systemd 配置留在 v13 根文件系统中，设备旧
业务已恢复运行。更新器顶层状态目录继续使用本机接口组，而 `staging` 和 `mcu-firmware`
两个私有子目录保持更新器自己的主组和 `0700`；这正是 r2 发现问题后新增的约束。

测试使用的 root bridge 容器镜像和临时容器均已移除；设备端的 r3 串口传输归档和解包目录
也已清理。本机受控副本继续保留在 Git 忽略的 `hardware/image-artifacts/local/` 下，并由制品
目录记录摘要。r2 的受控数据库归档继续保留在设备 root 管理的维护备份目录，便于后续审计
或显式处置；它不参与当前服务运行。

## 尚未覆盖的资格边界

本证据关闭的是“v13 受控维护安装路径”的第三阶段在线低权限门禁，不表示第三阶段的所有
镜像路径或第四阶段已经完成：

- 没有执行整机暖重启。当前调试串口是普通登录控制台，设备又拒绝非交互 SSH；在没有第二条
  可恢复管理通道时重启会失去后置审计和清理能力，因此本轮有意不冒险执行；
- 它不是 v16 写卡、冷启动或位级回读证据。v16 绑定较早提交 `42cc922c`，不包含 r3 所依赖的
  最终更新器私有目录用户组修复 `4120579c`，因此只能保留为历史离线候选；下一份写卡镜像
  必须从至少 `4120579c` 重新构建；
- 桥接后的业务程序尚未以 `ecobin-business` 身份完成真实投递、清运、UART 指令、拍照、COS
  上传和 OneNet 收发的全业务回归；
- MCU 更新编排、断电恢复、真实动作防重和业务发布回滚尚未完成真机验收；
- OneNet 仍由当前旧业务程序持有，通信代理不接收更新通知，更新器不执行更新，两个特权助手
  不接受变更动作，后端发布控制面也没有因此开放。

因此，本轮结论是：第三阶段永久层已在一台 v13 设备上通过受控原位安装及在线低权限验收；
整机暖重启、下一版镜像写卡和冷启动仍未验收；第四阶段继续关闭。本证据不是正式发布或量产
资格。
