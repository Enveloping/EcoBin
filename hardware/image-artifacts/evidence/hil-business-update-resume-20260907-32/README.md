- 候选复制前后 SHA-256 不变；v31 受控输入源复制前后 SHA-256 不变；

- HIL 镜像仍为 root 锁定、仅保留受控 orangepi 测试登录，自动登录关闭；
- 首次启动状态洁净，自动更新队列、断电测试钩子和业务数据库均未预置；
