## 处置

原始脱敏报告保存在 [invalid-report.json](invalid-report.json)，仅用于证明并回归
“运行中配置变化未使旧验收失效”的缺陷。修复后必须在 HSK 配置从轮次开始即生效的条件下
重新完成整轮验收；本报告不得改名或复制为通过证据。

本轮 MCU 使用 `factory-sim-1.0.0` 模拟固件，因此即使流程无错绑，也只能证明验收程序闭环，
不能替代真实传感器、屏幕、门锁、电机和门位的量产 HIL 证据。
